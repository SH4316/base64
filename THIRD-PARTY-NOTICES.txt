The runtime dependency graph is iconv-lite → safer-buffer → buffer,
iconv-lite → string_decoder → safe-buffer → buffer, and
buffer → base64-js + ieee754. chardet has no runtime dependencies.
Browser shims replace Node's built-in Buffer and string_decoder; no Node
runtime, filesystem API, network request or remote CDN is required.

vendor/manifest.json records exact bundled versions and SHA-256 checksums
of the bundle and all notice files. The build checks source and distribution
copies, installed versions and licenses, and required notice references.
Run npm run vendor:codecs after a reviewed dependency update.
