What is Base64?

Base64 represents binary data using a set of 64 text characters. It is useful for moving files or text through systems that only accept text. Encoded output is usually about one-third larger than the original.

Base64 is an encoding, not encryption. Anyone can decode it. The URL-safe option uses - and _ instead of + and /. Keep padding adds trailing = characters when needed. These options apply when you select Encode; the decoder accepts either alphabet and optional padding.

Paste text on the left and select Encode, or paste Base64 on the right and select Decode. You can also upload or drop a file into either panel. Binary results can be downloaded from the left panel. Use Ctrl+Enter (⌘+Enter on Mac) inside a panel to convert its contents.
